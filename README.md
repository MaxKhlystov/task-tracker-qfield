# 🛢️ Task Manager для QField

[![QField](https://img.shields.io/badge/QField-3.0%2B-blue)](https://qfield.org/)
[![Python](https://img.shields.io/badge/Python-3.9%2B-yellow)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-Proprietary-red)](LICENSE)

Комплексное решение для диспетчеризации полевых работ: **QField-плагин** для
планшетов в поле + **локальный сервер** для учёта смен, таймеров задач,
чек-листов и автоматической отправки отчётов в VK.

> Разработано для нефтегазовой отрасли. Работает офлайн в локальной сети,
> без выхода в интернет (кроме отправки уведомлений в VK).

---

## 📌 Возможности

- **Учёт смен работников** — выход на линию, пауза с причиной, возобновление, завершение
- **Таймеры задач** — автоматический подсчёт времени по каждой задаче отдельно
- **Чек-листы** — настраиваемые этапы работ по каждому типу задачи
- **Автогенерация отчётов** — `.docx` и `.pdf` по задаче и по итогам смены
- **Уведомления в VK** — текст + PDF-отчёт в личный диалог куратора
- **VK-бот (Long Poll)** — команда `статус` показывает, кто сейчас на линии
- **SQLite** — вся история хранится локально, ничего не теряется при перезапуске

## Быстрый старт

### 1. Клонировать репозиторий

```
git clone https://github.com/ВАШ_ЛОГИН/task-manager-qfield.git
cd task-manager-qfield
```

### 2. Поднять сервер

См. подробную инструкцию в [`server/README.md`](server/README.md).

Кратко:
```
cd server
pip install -r requirements.txt
# настроить переменные окружения (см. .env.example)
python app.py
```

### 3. Установить плагин в QField

См. [`qfield-plugin/README.md`](qfield-plugin/README.md).

Кратко: скопировать папку `qfield-plugin/` в каталог плагинов QField и
указать в `main.qml` IP-адрес сервера.

## 📂 Структура проекта

| Папка | Что внутри |
|-------|-----------|
| `server/` | Flask-сервер, шаблоны отчётов, генератор шаблонов |
| `plugin/` | QML-плагин для QField (3 файла + metadata) |
| `docs/` | Скриншоты, схема архитектуры |
| `server/reports/` | Сюда складываются готовые docx/pdf (в git не попадают) |

## Технологии

- **Python 3.9+**, Flask 3, docxtpl, SQLite
- **QML / Qt 6**, QField SDK 3.0+
- **LibreOffice** (headless) — для конвертации docx → pdf
- **VK Bots Long Poll API** — для бота и уведомлений
