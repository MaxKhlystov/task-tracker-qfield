# 📱 QField-плагин «Диспетчер задач»

QML-плагин для QField 3.0+, добавляющий в интерфейс:
- 🟢 кнопку **«Смена»** (выход на линию / пауза / завершение),
- 📋 кнопку **«Список задач»** (в работе / доступные, таймеры, чек-листы),
- ⚡ кнопку **«Принять по клику»** (быстрое принятие задачи с открытой карточки).

Взаимодействует с сервером из папки [`../server/`](../server/) по HTTP/JSON.

---

## 📋 Требования

- **QField 3.0+** (мобильный или десктопный)
- Планшет и сервер в **одной локальной сети** (Wi-Fi)
- Слой задач (`tasks`, `task`, `задачи`, `точки`, `points` — любое из этих имён)
  в текущем проекте QGIS

### Поля слоя задач

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `status` | ✅ | «В работе» / «Завершена» / пусто |
| `name` | ➖ | Название задачи |
| `description` | ➖ | Описание |
| `importance` | ➖ | Критичность |
| `planned_data` | ➖ | Плановая дата (YYYY-MM-DD) |
| `task_id` | ➖ | Внешний ID задачи (иначе берётся `fid`) |

---

## 📦 Установка

### Вариант 1: Ручное копирование

1. Найди папку плагинов QField:
   - **Android:** `/Android/data/ch.opengis.qfield/files/QField/plugins/`
   - **Windows:** `%APPDATA%\QField\plugins\`
   - **Linux:** `~/.local/share/QField/plugins/`
2. Скопируй туда **всю папку** `qfield-plugin/` и переименуй её в
   `task_list_plugin` (должно совпадать с `name` в `metadata.json`).
3. Перезапусти QField.

### Вариант 2: Через QField

Некоторые сборки QField позволяют установить плагин из ZIP-архива через
**Настройки → Плагины**. Заархивируй содержимое `qfield-plugin/` в ZIP
(без верхней папки) и укажи этот файл.

---

## ⚙️ Настройка

Открой `main.qml` и укажи IP-адрес сервера:

```qml
property string reportServerUrl: "http://192.168.1.101:5000/submit_task"
```

IP сервера узнаётся командой `ipconfig` (Windows) или `ip a` (Linux).
Планшет и сервер должны быть в **одной Wi-Fi сети**.

## 🎬 Как пользоваться

### 1. Выйти на линию

Нажми кнопку **🔴 Не на линии** на панели инструментов плагинов →
введи ФИО → **Выйти на линию**. Кнопка станет **🟢 Иванов И.И.**

### 2. Принять задачу

**Способ А — из списка:** открой **Список задач** → вкладка **Доступные** →
**Принять в работу**.

**Способ Б — по клику:** тапни по точке на карте → откроется карточка →
нажми **Принять по клику**.

После принятия задача уходит во вкладку **В работе**, таймер запускается
автоматически.

### 3. Работать по чек-листу

Отмечай галочки этапов по мере выполнения. Пока задача на паузе — чек-лист
заблокирован, нужно сначала нажать **Продолжить**.

### 4. Пауза

- **Пауза задачи:** кнопка **Пауза** в карточке задачи — таймер этой задачи остановится.
- **Пауза смены:** кнопка смены → **Поставить на паузу** → выбери причину
  (обед / техперерыв / другое). **Все активные задачи встанут на паузу автоматически.**

### 5. Завершить задачу

В карточке задачи — **Завершить**. Откроется диалог с ФИО исполнителя
(подставится из смены) и комментарием. После подтверждения:
- статус в слое станет «Завершена»,
- сервер сгенерирует docx+pdf и отправит в VK,
- задача исчезнет из списка (карта фильтруется).

### 6. Завершить смену

Кнопка смены → **Завершить смену**. Все активные задачи встанут на паузу,
сервер сформирует итоговый отчёт по смене и отправит его в VK.

## 🧩 Состав плагина

| Файл | Назначение |
|------|-----------|
| `metadata.json` | Метаданные плагина (имя, версия, автор) |
| `main.qml` | Точка входа: список задач, диалог завершения, синхронизация с сервером |
| `QuickAcceptButton.qml` | Кнопка «Принять по клику» с открытой карточки |
| `ShiftPanel.qml` | Кнопка смены + диалоги выхода/паузы/завершения |

---

## 🔄 Синхронизация с сервером

- Каждые **15 секунд** плагин запрашивает `/shift/status` и обновляет таймеры и чек-листы.
- Таймеры «тикают» локально раз в секунду (`uiTick`), но реальное время
  всегда берётся с сервера — если приложение перезапустится, ничего не потеряется.
- Все действия (старт/пауза/резюм/чек-лист) сначала идут на сервер, потом
  UI перерисовывается из ответа.

## 🐛 Решение проблем

| Симптом | Что проверить |
|---------|---------------|
| «Слой задач не найден» | Имя слоя в проекте QGIS из списка `tasks`/`task`/`задачи`/`точки`/`points` |
| «Сначала выйдите на линию» | Нажми кнопку смены и введи ФИО |
| Кнопка смены не восстанавливается после перезапуска | Это нормально: имя живёт в памяти текущей сессии. Введи ФИО заново — сервер сам найдёт открытую смену через `/shift/active` |
| Чек-лист не отмечается | Задача на паузе? Нажми **Продолжить** |
| «Сервер вернул ошибку (0)» | IP сервера неверный или сервер не запущен |
